# Snapwise updates

Release downloads and the update feed for **Snapwise**, a free, privacy-first screenshot app for macOS (macOS 14+, Apple silicon and Intel).

- **Download:** see [Releases](https://github.com/ranbd4/snapwise-updates/releases). Open the DMG and drag Snapwise to Applications.
- **Updates:** Snapwise checks `appcast.xml` in this repo once a day. Every update is signed with an EdDSA key, and Snapwise refuses any download whose signature doesn't match.

The source code is kept in a separate private repository.
